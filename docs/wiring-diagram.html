01

The system

Follow any arrow from top to bottom and you have a complete request. Container addresses are deliberately absent: Docker assigns them in start order and they change whenever the stack is recreated.

Three things the drawing makes obvious

The amber path terminates at one box

Jellyfin is the only thing the house can reach, and that arrow never passes through Caddy. Every other service is on a blue path or on no path at all.

sshd sits outside every container

It connects straight to the disk, bypassing Docker and Caddy — which is why it keeps working when both are broken. That independence is deliberate: it is the way back in.

Two boxes share one drive

The library and its backup are both inside the /mnt/t7 outline — which the drawing shows better than prose can. It is the top entry in the gap list.

The one arrow not drawn

Syncthing’s sync port, :22000, is also open on the house WiFi. It is safe there because every peer must be approved by device ID and it carries no admin access — but it is a second thing listening on the amber interface, so it is worth knowing about rather than discovering.

02

What Caddy actually changes

The clearest way to see the point of a reverse proxy is to draw the same system without one.

The prediction has been tested twice. Adding the downloader meant one Caddy block and one more port on an existing certificate; adding n8n meant the same again. Neither was a new security decision.

Why SSH is drawn outside

It runs on the host, not in a container, so it needs neither Docker’s port forwarding nor Caddy’s routing. That is the way back in when something else is broken.

Why the TV skips Caddy

Routing it through Caddy would mean installing a certificate on every roommate device. Instead that traffic stays on the house network in plain HTTP, where the WiFi’s own encryption covers it.

Why two boxes have no address

n8n and ollama publish no host port at all — Caddy and n8n reach them by container name. A port that is never published cannot be published to the wrong interface.

Why qBittorrent has no interface

It shares gluetun’s namespace rather than having its own, so the tunnel is the only way out. A dead tunnel means no connection at all, rather than a fallback to the house line.

Why one arrow is read-only

Jellyfin can read the library but not change it, so no bug can delete it. The cost is no subtitle downloads and no metadata sidecars — and it matters more now that backups live on the same drive.

Why the backup arrow is dashed

It is not a live connection. A systemd timer runs bin/homie-backup nightly; the rest of the time that path does not exist.
